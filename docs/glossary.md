# PIMS Glossary

Canonical vocabulary of the Pharmacy Inventory Management System (PIMS): pharmacy, Bangladesh business
and technical terms used across the requirements, design, engineering and operations documents.

| Field          | Value                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------- |

| Version        | 1.0                                                                                            |
| Status         | Draft for M0 review                                                                            |
| Owner          | Engineering lead                                                                               |
| Approver       | Product owner (pharmacy owner) for business terms                                              |
| Last updated   | 2026-10-06                                                                                     |
| Change control | Pull request; a term changed here is updated in every document that uses it in the same change |

## How to use this glossary

- **This glossary is canonical for definitions.** The [SRS](requirements/SRS.md) (section 1.3) and the
  [database design](database/database-design.md) (section 1.3) repeat a few terms for convenience;
  where a definition differs, this glossary prevails and the other document is corrected.
- It **defines words, not rules.** Business rules and their values (limits, thresholds, defaults) are
  owned by the SRS (requirement IDs `FR-*`, `NFR-*`, configuration parameters `CFG-*`); roles and
  permissions by the [security model](security/security-model.md); tables, columns and functions by the
  [database design](database/database-design.md). Entries below cite those IDs instead of restating them.
- Code identifiers are written in `monospace` and are illustrative; the database design is
  authoritative for their exact names.
- Bangla terms appear in parentheses with a romanized spelling, for example due (বাকি, _baki_).
- Money is written as ৳1,234.50 and stored as integer paisa (123450). Dates are ISO 8601 (2026-10-06);
  times are Asia/Dhaka unless stated otherwise.

## 1. Pharmacy and medicines

| Term                            | Definition                                                                                                                                                                                                                                                           | See also                                |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Barcode                         | Machine-readable code on a pack, usually EAN-13 from the manufacturer. A medicine may have several barcodes, each linked to one pack level and unique within the organization. Items without one receive an internal Code 128 barcode (FR-CAT-004, FR-CAT-005).      | Pack, EAN-13                            |
| Base unit                       | The smallest sellable unit of a medicine: one tablet, capsule, ampoule, vial, sachet, tube or bottle. Every stock quantity, movement and allocation is an integer number of base units (constraint C-05).                                                            | Pack, Pack size                         |
| Batch (lot)                     | Stock of one medicine produced together by the manufacturer and identified by a batch number and expiry date on the pack. In PIMS a **lot** is one `batches` row: stock of one medicine batch at one branch with one expiry date, MRP and unit cost.                 | Batch number, FEFO, Lot                 |
| Batch number                    | The manufacturer's lot code printed on the pack, entered at goods receipt (assumption A-02).                                                                                                                                                                         | Batch, GRN                              |
| Brand name (trade name)         | The name under which a manufacturer markets a medicine. Napa and Ace are two brands that both contain paracetamol. Counter staff usually search by brand.                                                                                                            | Generic name                            |
| Cold-chain item                 | A medicine that must be stored at 2 to 8 °C, such as insulin. Recorded as a storage condition; not returnable by default (FR-CAT-013).                                                                                                                               | Sale return                             |
| Controlled drug                 | A narcotic or psychotropic medicine (schedule `controlled`). | Controlled-drug register        | Immutable, chronological record of every movement of each controlled medicine at a branch, with a running balance per branch and medicine (FR-CDR-006, FR-CDR-007). Corrections are compensating entries only.                                                       | Ledger, Controlled drug                 |
| DAR number                      | Drug registration number assigned by DGDA to a registered medicine; optional catalog attribute (FR-CAT-013).                                                                                                                                                         | DGDA                                    |
| Dispense                        | To hand over a medicine to a customer against a sale. For controlled drugs only authorized users may dispense (FR-CDR-003; permission in the security model).                                                                                                        | Controlled drug                         |
| Dosage form                     | The physical form of a medicine: tablet, capsule, syrup, suspension, injection, infusion, cream, ointment, gel, drops, inhaler, suppository, powder, solution or other (FR-CAT-002). Held in the `dosage_forms` reference table.                                     | Strength                                |
| Drug schedule                   | Regulatory class of a medicine in PIMS: OTC, Rx or Controlled (enum `drug_schedule`: `otc`, `rx`, `controlled`). Changing it is restricted to the Owner by default and audited (FR-CAT-007).                                                                         | OTC, Rx, Controlled drug                |
| Expired                         | A lot whose expiry date is earlier than the business date. It becomes non-sellable and non-transferable automatically and can only be written off or returned to the supplier (FR-INV-009).                                                                          | Near expiry, Write-off                  |
| Expiry date                     | Date printed on the pack after which the batch must not be used. An expiry given as month and year is stored as the last day of that month (FR-INV-001).                                                                                                             | FEFO                                    |
| FEFO (first-expiry-first-out)   | Allocation rule: a sale takes stock from the sellable lot with the earliest expiry date first, so that stock expiring sooner leaves the shelf first. Implemented in the database for every sale (ADR-0008).                                                          | FIFO, Sellable quantity                 |
| Generic name                    | The non-proprietary name of the active ingredient or combination, for example paracetamol or omeprazole. Generics are an organization master table; search by generic lists all brands containing it.                                                                | Brand name                              |
| Manufacturer (company)          | The pharmaceutical company that makes and labels a medicine. Counter staff in Bangladesh usually call it the "company". Manufacturers are an organization master table.                                                                                              | Supplier                                |
| Medicine                        | A catalog item in PIMS: a brand of a generic in one dosage form and strength from one manufacturer, with its pack hierarchy, barcodes, schedule and loyalty eligibility (FR-CAT-001).                                                                                | Catalog                                 |
| MRP (maximum retail price)      | The highest price at which a pack may be sold, printed on the pack and inclusive of taxes. The PIMS sale price can never exceed MRP (constraint C-11). See also MRP-inclusive pricing in section 5.                                                                  | Sale price                              |
| Narcotic, psychotropic          | The two classes of controlled drugs: narcotics (for example opioid analgesics) and psychotropics (for example some sedatives). A controlled medicine should record its class (FR-CDR-001).                                                                           | Controlled drug                         |
| Near expiry                     | A lot whose expiry falls within a configured threshold: alert windows of 30, 60 and 90 days by default (CFG-08). A separate optional sale block applies only when configured (CFG-40, default 0 days).                                                               | Expired, Expiry report                  |
| OTC (over the counter)          | A medicine that may be sold without a prescription (schedule `otc`).                                                                                                                                                                                                 | Rx                                      |
| Pack                            | One level of a medicine's packaging, such as piece, strip or box, with an integer number of base units. A medicine has one to three pack levels; one is the default sale unit and one the default purchase unit (FR-CAT-003).                                        | Pack hierarchy, Base unit               |
| Pack hierarchy                  | The ordered pack levels of a medicine, for example box, strip (পাতা, _pata_) and piece. Example: a box of 10 strips of 10 tablets is 100 base units; a strip is 10.                                                                                                  | Pack size, Conversion factor            |
| Pack size (conversion factor)   | The number of base units in one pack level (the base unit's factor is 1). It cannot change once stock movements exist for the medicine; a different pack size is a new pack level (FR-CAT-003).                                                                      | Base unit                               |
| Pharmacist (registered)         | A staff member whose profile records a Pharmacy Council of Bangladesh registration number (FR-IAM-015); by default the only Salesmen allowed to dispense controlled drugs (FR-CDR-003).                                                                              | Salesman                                |
| Prescriber                      | The doctor who issued a prescription, identified by name and BMDC registration number.                                                                                                                                                                               | BMDC                                    |
| Prescription                    | A prescriber's written order for medicines. Required in detail for controlled drugs (valid 30 days by default, CFG-16); optionally confirmed ("prescription seen") for Rx medicines (CFG-41). Images are stored in a private bucket (FR-CDR-005).                    | Rx, Controlled drug                     |
| Quarantine                      | A Branch Manager or Owner action that blocks a lot from sale and transfer, for example during a recall, until it is released (FR-INV-010).                                                                                                                           | Recall                                  |
| Rack (shelf) location           | Where a medicine is kept in a branch, recorded per branch to help staff find stock (FR-CAT-006).                                                                                                                                                                     | Reorder level                           |
| Recall                          | Withdrawal of a batch by the manufacturer or regulator. Handled in PIMS by quarantine and return to supplier. Not to be confused with a transfer recall (section 3).                                                                                                 | Quarantine, Purchase return             |
| Rx (prescription-only medicine) | A medicine that may be sold only against a prescription (schedule `rx`).                                                                                                                                                                                             | OTC, Prescription                       |
| Sellable quantity               | Stock of a medicine at a branch that may be sold now: lots that are not expired, not quarantined and outside the near-expiry sale block. Low stock and FEFO use it (FR-INV-019).                                                                                     | On-hand quantity                        |
| Strength                        | The amount of active ingredient per unit or volume, for example "500 mg" or "250 mg/5 ml" (FR-CAT-001).                                                                                                                                                              | Dosage form                             |

## 3. Inventory and purchasing

| Term                                | Definition                                                                                                                                                                                                                                                                                                                                                 | See also                         |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Adjustment (stock adjustment)       | A manual change to a lot's quantity with a mandatory reason: damage, loss, theft, expired write-off, count correction, found stock or other. Audited. Salesmen cannot adjust; a Branch Manager may adjust up to ৳5,000 cost value per adjustment (CFG-12) and larger adjustments need Owner approval (FR-INV-008). Written only by the `adjust_stock` RPC. | Write-off, Approval              |
| Blind count                         | A stock count in which counters do not see the expected (system) quantity, which reduces confirmation bias. On by default (CFG-14).                                                                                                                                                                                                                        | Stock count                      |
| Goods receipt (GRN)                 | Goods received note: the record of goods received from a supplier, line by line with batch number, expiry, quantity, cost and MRP. Posting it creates or increases lots and writes `purchase_receipt` movements (RPC `receive_goods`). Numbered per branch, for example `MPR-GRN-2026-000007`.                                                             | Purchase order, Supplier invoice |
| In transit                          | Stock that has been dispatched from the source branch and not yet received at the destination. It is neither sellable nor part of either branch's on-hand quantity, and is valued at its dispatched cost (FR-TRF-007).                                                                                                                                     | Stock transfer                   |
| Inventory movement (stock movement) | One row of the stock ledger (`inventory_movements`): a signed quantity of one lot with a movement type (for example `purchase_receipt`, `sale`, `transfer_out`, `expiry_writeoff`), document reference, user and time. | Low stock                           | A medicine whose sellable quantity at a branch is at or below its reorder level (FR-INV-019).                                                                                                                                                                                                                                                              | Reorder level                    |
| Lot                                 | See Batch (lot) in section 1. In technical documents "lot" refers to the `batches` row.                                                                                                                                                                                                                                                                    | Batch                            |
| On-hand quantity                    | The quantity of a lot physically held at the branch (`batches.quantity_on_hand`), a projection of the stock ledger. It can never be negative (database constraint).                                                                                                                                                                                        | Projection, Sellable quantity    |
| Opening stock (opening balance)     | Stock that existed before a branch started using PIMS, loaded once per lot at go-live through import or the `add_opening_stock` RPC (movement type `opening_balance`).                                                                                                                                                                                     | Go-live, Data import             |
| Purchase order (PO)                 | An optional order to a supplier listing medicines and quantities. Goods may also be received without one. Numbered per branch, for example `MPR-PO-2026-000015`.                                                                                                                                                                                           | Goods receipt                    |
| Purchase return                     | Return of stock to a supplier (for example near-expiry, damaged, wrong item or recall), which reduces the lot and credits the supplier ledger (RPC `process_purchase_return`).                                                                                                                                                                             | Supplier ledger                  |
| Reorder level                       | Per-branch threshold in base units at or below which a medicine is low stock; an optional reorder quantity suggests how much to buy (FR-CAT-006).                                                                                                                                                                                                          | Low stock, Reorder forecasting   |
| Slow mover, fast mover              | Medicines ranked by sales velocity over a period in a branch; reported to guide purchasing and reduce dead stock.                                                                                                                                                                                                                                          | Reports                          |
| Stock count (cycle count)           | A counting session for all or part of a branch's stock. Differences between counted and expected quantities are posted as `count_correction` movements when the count is completed.                                                                                                                                                                        | Blind count, Adjustment          |
| Stock ledger                        | The immutable, append-only table of inventory movements; the single source of truth for stock. Lot quantities are projections maintained in the same transaction (ADR-0008).                                                                                                                                                                               | Ledger, Projection               |
| Stock transfer                      | Movement of stock between two branches of one organization: requested by the destination, dispatched by the source (batch-level), received by the destination; may be rejected, cancelled or recalled. Numbered per organization, for example `TRF-2026-000031`.                                                                                           | In transit, Transfer recall      |
| Supplier                            | A distributor or company depot from which a branch buys medicines. Suppliers are organization master data with a ledger of invoices, payments and returns.                                                                                                                                                                                                 | Manufacturer, Supplier ledger    |
| Supplier invoice                    | The supplier's bill for goods received, with a due date derived from payment terms; overdue invoices are listed (FR-PUR-013).                                                                                                                                                                                                                              | Supplier due                     |
| Supplier ledger, supplier due       | The append-only record of what the organization owes each supplier (invoices, payments, returns, adjustments); the supplier due is its balance.                                                                                                                                                                                                            | Ledger                           |
| Transfer recall                     | Owner action that returns a dispatched (in-transit) transfer to the source branch, for example when the destination never receives it.                                                                                                                                                                                                                     | Stock transfer, Recall           |
| Write-off                           | Removal of stock that cannot be sold, such as expired or damaged goods, as an adjustment or expiry write-off movement with a reason. ## 5. Money, pricing and reporting

| Term                      | Definition                                                                                                                                                                                                               | See also               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------- |

## 13. Maintaining this glossary

1. Add a term when a document, issue or screen uses a word that a new engineer or the Owner could
   misread, or when two documents use different words for the same thing.
2. Place it in the most specific section, in alphabetical order, with a definition of one or two
   sentences that cites the owning requirement, configuration parameter or decision instead of
   restating its values in detail.
3. If the term has an acronym, add it to [section 12](#12-acronyms-and-abbreviations).
4. If a definition changes, search the documentation set and the `src/i18n/locales` files for the term
   and update them in the same pull request.
5. Never redefine here a rule owned by another document; link to it.
