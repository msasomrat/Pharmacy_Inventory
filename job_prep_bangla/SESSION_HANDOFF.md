## ৫. কীভাবে আবার বানাবে (সব কমান্ড `job_prep_bangla/` থেকে)
Chromium + Playwright আগে থেকে ইনস্টল থাকে (`require('playwright')`)। Node স্ক্রিপ্ট `.cjs` (রিপোর package.json "type: module")।
```bash
# লোগো, প্রোফাইল, কভার, স্বাগত পোস্ট
python3 tools/make_logo.py tools/rosayon_dorbar_logo_white.png branding
# মাস ১ এর PDF
HTML_DIR=/tmp/h python3 tools/render.py && node tools/pdf.cjs /tmp/h/monthly.html month1/Month1_Bangla_Monthly_Prep.pdf
for i in 1 2 3 4; do node tools/pdf.cjs /tmp/h/week${i}_exam.html month1/Week${i}_Exam_with_Answers.pdf; done
python3 tools/calendar_docx.py month1/Month1_Content_Calendar.docx
# মাস ১ এর পোস্টের ছবি
python3 tools/posts.py month1/posts && node tools/shots.cjs $PWD/tools/postjobs.json && rm -rf tools/postjobs tools/postjobs.json
# CAAB
python3 tools/caab_notice.py caab/posts/00_Nov18_ExamNotice
python3 tools/caab_series.py        # caab/caab_series.json থেকে পোস্ট + ৩টা PDF
```
- `tools/fonts/` এ সব ফন্ট (Noto Sans Bengali, Hind Siliguri, Anek Bangla, Noto Serif Bengali) লোকাল আছে।
- ডিজাইন বদলাতে: পোস্টের CSS `tools/posts.py`, PDF এর CSS `tools/render.py`।
- নতুন মাস/সিরিজ: weeks JSON বা caab_series.json এর মতো একই স্কিমায় ডেটা বানাও (স্কিমা `tools/weeks/BRIEF.md` আর `caab/data/COMPOSE.md` এ)।
